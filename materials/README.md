## Принцип редактирования

- Сохраняем полезные объяснения, примеры, команды и практические сценарии.
- Исправляем ошибки, неудачные формулировки и оформление.
- Не сокращаем подробный материал только ради размера файла.
- Краткие версии редактируются отдельно и не заменяют полный конспект.
