## Что такое замыкание?

**Короткий ответ**

Замыкание — это внутренняя функция, которая продолжает использовать данные внешней функции даже после завершения внешней функции.

```python
def make_multiplier(factor):
    def multiply(value):
        return value * factor

    return multiply


double = make_multiplier(2)
print(double(5))  # 10
```

Здесь `multiply` сохраняет доступ к `factor`.

### Частая ловушка в цикле

Замыкание запоминает имя, а не снимок его значения:

```python
functions = [lambda: number for number in range(3)]
print([func() for func in functions])  # [2, 2, 2]
```

Значение можно зафиксировать аргументом по умолчанию:

```python
functions = [lambda number=number: number for number in range(3)]
```

## Какие области видимости существуют?

Поиск имени подчиняется правилу **LEGB**:

1. **Local** — текущая функция;
2. **Enclosing** — внешние функции;
3. **Global** — модуль;
4. **Builtins** — встроенные имена.

```python
value = "global"


def outer():
    value = "enclosing"

    def inner():
        value = "local"
        return value

    return inner()
```

Блоки `if`, `for`, `while` и `with` не создают отдельную область видимости. Comprehension в Python 3 имеет собственную внутреннюю область и не оставляет переменную цикла снаружи.

## Для чего нужны `global` и `nonlocal`?

- `global` позволяет переназначить имя из области модуля;
- `nonlocal` позволяет переназначить имя ближайшей внешней функции.

```python
def make_counter():
    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment
```

Без `nonlocal` присваивание создало бы локальное имя `count`. Частое использование `global` обычно указывает на неудачное управление состоянием.

## Что такое аннотации типов?

Аннотации типов показывают, значения каких типов ожидает код. Они делают код понятнее и помогают статическим анализаторам находить ошибки до запуска.

```python
def find_user(user_id: int) -> dict[str, object] | None:
    ...
```

Python обычно не проверяет аннотации во время выполнения. Их используют IDE, документация и статические анализаторы вроде `mypy` и `pyright`.

```python
age: int = "thirty"  # интерпретатор обычно не запретит
```

`Any` фактически отключает статическую проверку для значения, а `object` означает «объект любого типа, но операции над ним нужно доказать проверками».

### Type hints и Pydantic — одно и то же?

Нет. Type hints описывают типы и обычно проверяются статически. Pydantic — сторонняя библиотека, которая читает аннотации и валидирует данные во время выполнения. Её применяют на границах системы: для API-запросов, конфигурации, сообщений и внешних данных.

## Что такое чистая функция?

Чистая функция при одинаковых аргументах возвращает одинаковый результат и не изменяет данные за своими пределами.

У неё нет наблюдаемых побочных эффектов: она не меняет глобальные переменные, переданные объекты, файлы или внешние системы.

Коротко:

- при одинаковых аргументах возвращает одинаковый результат;
- не меняет внешнее состояние и не создаёт наблюдаемых побочных эффектов.

```python
def total_with_tax(amount, rate):
    return amount * (1 + rate)
```

Чистые функции проще тестировать и комбинировать. Но ввод-вывод, логирование и работа с сетью по природе имеют побочные эффекты, поэтому весь проект чистым быть не обязан.

## Какие парадигмы поддерживает Python?

Python позволяет писать код в разных стилях, поэтому его называют мультипарадигменным языком:

- процедурное программирование;
- объектно-ориентированное;
- функциональный стиль;
- императивный стиль;
- асинхронное событийное программирование.

Python не является чисто функциональным языком, но поддерживает функции первого класса, замыкания, генераторы, `map`, `filter`, `functools` и `itertools`.
