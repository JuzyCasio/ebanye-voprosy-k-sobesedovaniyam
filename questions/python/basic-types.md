## Какие основные типы существуют в Python?

**Короткий ответ**

Основные встроенные типы можно разделить на несколько групп:

- числа: `int`, `float`, `complex`;
- логический тип: `bool`;
- текст: `str`;
- последовательности: `list`, `tuple`, `range`;
- отображения: `dict`;
- множества: `set`, `frozenset`;
- бинарные данные: `bytes`, `bytearray`, `memoryview`;
- отсутствие значения: `None`, имеющее тип `NoneType`.

| Группа | Типы | Пример |
|---|---|---|
| целые и вещественные числа | `int`, `float` | `10`, `3.14` |
| комплексные числа | `complex` | `2 + 3j` |
| логические значения | `bool` | `True`, `False` |
| текст | `str` | `"hello"` |
| последовательности | `list`, `tuple`, `range` | `[1, 2]`, `(1, 2)`, `range(3)` |
| отображения | `dict` | `{"id": 10}` |
| множества | `set`, `frozenset` | `{1, 2}`, `frozenset({1, 2})` |
| бинарные данные | `bytes`, `bytearray`, `memoryview` | `b"abc"` |
| отсутствие значения | `NoneType` | `None` |

`bool` является подклассом `int`: `True == 1` и `False == 0`. Это особенность системы типов Python, но обычно логические значения не стоит использовать вместо чисел.

## Что означает динамическая и сильная типизация?

**Короткий ответ**

Python — язык с динамической и сильной типизацией.

- **Динамическая типизация:** тип имеет объект, а не имя переменной; проверка типов происходит во время выполнения.
- **Сильная типизация:** Python не выполняет произвольные неявные преобразования между несовместимыми типами.

```python
value = 10
value = "ten"  # допустимо: имя связано с другим объектом

"10" + 5      # TypeError: строка не складывается с числом
```

Аннотация типа сама по себе не меняет поведение интерпретатора:

```python
age: int = 30
age = "thirty"  # интерпретатор разрешит, но статический анализатор предупредит
```

Аннотации помогают людям, IDE и инструментам вроде `mypy` или `pyright`.

## Что такое изменяемые и неизменяемые объекты?

**Короткий ответ**

Изменяемый объект можно изменить после создания, сохранив его идентичность. Неизменяемый объект изменить нельзя: результат операции является другим объектом либо ранее созданным объектом, который интерпретатор может безопасно переиспользовать.

### Изменяемые встроенные типы

- `list`;
- `dict`;
- `set`;
- `bytearray`.

Возможность изменять данные через `memoryview` зависит от того, доступен ли исходный буфер для записи.

### Неизменяемые встроенные типы

- **числа:** `int`, `float`, `complex`;
- **логические значения:** `bool`;
- **строки:** `str`;
- **кортежи:** `tuple`;
- **неизменяемые множества:** `frozenset`;
- **диапазоны:** `range`;
- **байтовые строки:** `bytes`;
- **отсутствие значения:** `NoneType`.

```python
items = [1, 2]
same_items = items
items.append(3)       # изменён существующий список

text = "Py"
old_text = text
text += "thon"        # имя text теперь связано с другой строкой
```

`id()` позволяет увидеть идентичность объекта, но прикладную логику на конкретных значениях `id()` строить нельзя. Интерпретатор может кешировать и переиспользовать некоторые неизменяемые объекты.

## Почему изменяемость важна?

Изменяемость влияет на:

- появление побочных эффектов в функциях;
- поверхностное и глубокое копирование;
- значения аргументов по умолчанию;
- возможность использовать объект как ключ `dict` или элемент `set`;
- безопасную передачу и совместное использование данных.

```python
def add_item(items):
    items.append("new")


data = []
add_item(data)
print(data)  # ["new"]
```

Функция изменила тот же список, на который ссылается `data`.

Если исходный объект менять не нужно, можно вернуть новую коллекцию:

```python
def with_item(items):
    return [*items, "new"]
```

## Может ли неизменяемый контейнер содержать изменяемый объект?

Да. Нельзя заменить элементы самого кортежа, но можно изменить вложенный изменяемый объект.

```python
value = (1, ["a"])
value[1].append("b")

print(value)  # (1, ["a", "b"])
```

Неизменяемость контейнера не означает глубокую неизменяемость всех вложенных объектов. Такой кортеж также нельзя хешировать, потому что он содержит нехешируемый список.

## Что хранит переменная?

**Короткий ответ**

Переменная в Python — это имя, связанное с объектом. Обычное присваивание не копирует объект, а создаёт ещё одну ссылку на него.

```python
first = [1, 2]
second = first
second.append(3)

print(first)  # [1, 2, 3]
```

Оба имени ссылаются на один список.

## Как объекты передаются в функцию?

**Короткий ответ**

Параметр функции становится новым локальным именем, связанным с переданным объектом. Изменение переданного изменяемого объекта видно снаружи, а переназначение локального имени — нет.

```python
def change(items):
    items.append(3)  # изменяет переданный объект
    items = [9]      # переназначает только локальное имя


values = [1, 2]
change(values)
print(values)  # [1, 2, 3]
```

Эту модель называют *call by sharing* или передачей объектной ссылки.

## В чём проблема изменяемого аргумента по умолчанию?

**Короткий ответ**

Значения аргументов по умолчанию вычисляются один раз — при создании функции. Изменяемый объект будет общим для всех вызовов, в которых аргумент не передан.

```python
# Плохо
def collect(value, result=[]):
    result.append(value)
    return result
```

```python
# Хорошо
def collect(value, result=None):
    if result is None:
        result = []
    result.append(value)
    return result
```

Иногда общее состояние создают намеренно, но тогда это должно быть явно и понятно из кода.
