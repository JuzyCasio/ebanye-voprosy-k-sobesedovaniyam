## Что такое последовательность?

**Короткий ответ**

Последовательность — это набор элементов, расположенных в определённом порядке. Обычно к элементу можно обратиться по номеру — индексу — и получить часть элементов с помощью среза.

Основные встроенные последовательности: `list`, `tuple`, `range`, `str`, `bytes` и `bytearray`.

```python
values = ["a", "b", "c"]

values[0]   # "a"
values[-1]  # "c"
values[1:]  # ["b", "c"]
```

### Последовательность и итерируемый объект — одно и то же?

Нет. Последовательность является итерируемым объектом, но не каждый итерируемый объект является последовательностью. Например, `set`, `dict` и генератор можно перебирать циклом, но они не поддерживают обычный позиционный доступ `obj[0]`.

## Какие операции поддерживают последовательности?

Для большинства последовательностей доступны:

```python
value in sequence
value not in sequence
sequence[index]
sequence[start:stop:step]
len(sequence)
min(sequence)
max(sequence)
sequence.count(value)
sequence.index(value)
```

Операции `+` и `*` поддерживаются не всеми последовательностями:

```python
[1, 2] + [3]  # [1, 2, 3]
"ab" * 3      # "ababab"
```

Конкатенация неизменяемой последовательности в цикле может создавать много промежуточных объектов. Для большого числа строк используют `str.join()`.

## Чем список отличается от кортежа?

| `list` | `tuple` |
|---|---|
| изменяемый | неизменяемый |
| литерал `[1, 2]` | литерал `(1, 2)` |
| нельзя хешировать | хешируем, если хешируемы все элементы |
| подходит для изменяемой коллекции | подходит для фиксированного набора позиций |
| имеет методы изменения | не имеет методов изменения |

**Короткий ответ**

Список можно изменять после создания, а кортеж нельзя.

Список используют, когда элементы нужно добавлять, удалять или заменять. Кортеж подходит для фиксированного набора значений, который не должен меняться.

Кортеж из одного элемента обязательно содержит запятую:

```python
number = (1)       # int
one_item = (1,)    # tuple
```

Скобки не создают кортеж сами по себе — кортеж создаёт запятая.

## Что такое `range`?

`range` описывает последовательность целых чисел. Его часто используют в циклах. Значение `stop` в результат не входит.

```python
range(5)         # 0, 1, 2, 3, 4
range(2, 6)      # 2, 3, 4, 5
range(10, 0, -2) # 10, 8, 6, 4, 2
```

`range` не хранит в памяти весь список чисел, а запоминает только начало, конец и шаг. Он поддерживает `len()`, индексы, срезы и быструю проверку принадлежности.

`range` является iterable, но не iterator: каждый `iter(range(...))` создаёт новый независимый итератор.

## Что такое срез?

**Короткий ответ**

Срез получает часть последовательности. Общая форма: `sequence[start:stop:step]`. Граница `stop` не включается.

```python
values = [0, 1, 2, 3, 4]

values[1:4]   # [1, 2, 3]
values[:3]    # [0, 1, 2]
values[::2]   # [0, 2, 4]
values[::-1]  # [4, 3, 2, 1, 0]
```

У среза могут быть отрицательные границы и шаг. Нулевой шаг недопустим.

Срез списка создаёт новый внешний список, но является поверхностной копией: вложенные изменяемые объекты остаются общими.

### Можно ли присваивать значение срезу?

Да, но только у изменяемых последовательностей, например у списка:

```python
values = [0, 1, 2, 3]
values[1:3] = [10, 20, 30]

print(values)  # [0, 10, 20, 30, 3]
```

При обычном срезе размер заменяемой и новой частей может различаться.
