## Как работают логические операторы?

- `not value` возвращает `bool`;
- `left and right` возвращает первый ложный операнд либо последний;
- `left or right` возвращает первый истинный операнд либо последний.

```python
name = provided_name or "anonymous"
result = user is not None and user.is_active
```

`and` и `or` используют короткое замыкание: правый операнд вычисляется только при необходимости.

```python
value is not None and value.process()
```

Они возвращают не обязательно `True` или `False`:

```python
[] or "default"  # "default"
"value" and 10   # 10
```

## Как выбрать структуру данных?

| Требование | Подходящий тип |
|---|---|
| упорядоченная изменяемая последовательность | `list` |
| фиксированная последовательность | `tuple` |
| соответствие ключей значениям | `dict` |
| уникальные элементы и быстрый поиск принадлежности | `set` |
| неизменяемое множество, которое нужно хешировать | `frozenset` |
| неизменяемый текст | `str` |
| неизменяемые бинарные данные | `bytes` |
| изменяемые бинарные данные | `bytearray` |

Структуру выбирают по тому, что с данными нужно делать:

- нужны порядок, дубликаты и индексы — `list`;
- нужна уникальность и частые проверки `in` — `set`;
- нужен быстрый поиск значения по смысловому ключу — `dict`;
- нужно зафиксировать набор позиций — `tuple`.

Не стоит выбирать структуру только потому, что она знакомее. Например, постоянные проверки принадлежности в большом списке могут быть признаком того, что нужен `set`.

## Какие преобразования между коллекциями важно знать?

Тип коллекции можно изменить с помощью конструкторов `list()`, `tuple()`, `set()` и `dict()`.

```python
list((1, 2))                       # [1, 2]
tuple([1, 2])                      # (1, 2)
set([1, 1, 2])                    # {1, 2}
dict([("name", "Alex"), ("age", 30)])
list({"a": 1, "b": 2})            # ["a", "b"] — ключи
```

Преобразование обычно создаёт новый контейнер, но не обязательно копирует вложенные объекты. При переходе к `set` теряются дубликаты и нельзя полагаться на исходный порядок.
