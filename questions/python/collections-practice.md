## Чем `==` отличается от `is`?

**Короткий ответ**

`==` сравнивает значения объектов, а `is` проверяет, являются ли операнды одним и тем же объектом.

```python
first = [1, 2]
second = [1, 2]

first == second  # True
first is second  # False
```

С `None` используют `is`:

```python
if value is None:
    ...
```

Нельзя использовать `is` для сравнения строк или чисел по значению. Из-за кеширования объектов это иногда случайно работает, но результат не является надёжным.

## Какие значения считаются ложными?

**Короткий ответ**

В логическом контексте ложными считаются:

- `None`;
- `False`;
- числовой ноль: `0`, `0.0`, `0j`;
- пустые коллекции и строки: `""`, `[]`, `()`, `{}`, `set()`;
- пользовательские объекты, для которых `__bool__()` возвращает `False` или `__len__()` возвращает `0`.

Остальные объекты обычно считаются истинными.

```python
if not items:
    print("Коллекция пуста")
```

Не следует заменять точную проверку на `None` общей проверкой истинности, если `0`, пустая строка или пустой список являются допустимыми значениями:

```python
if value is None:
    value = default
```

## Что такое распаковка?

Распаковка связывает элементы итерируемого объекта с несколькими именами:

```python
name, age = ("Alex", 30)
```

Звёздочка собирает оставшиеся элементы:

```python
first, *middle, last = [1, 2, 3, 4]

# first == 1
# middle == [2, 3]
# last == 4
```

Распаковку применяют и при вызове функции:

```python
args = (10, 20)
kwargs = {"timeout": 5}

some_function(*args, **kwargs)
```

`*` распаковывает позиционные аргументы, `**` — именованные.

## Что такое list, set и dict comprehension?

Это компактный синтаксис создания коллекций из итерируемого объекта.

```python
squares = [number**2 for number in range(5)]

even_squares = {
    number**2
    for number in range(10)
    if number % 2 == 0
}

lengths = {
    word: len(word)
    for word in ["api", "python", "test"]
}
```

Слишком сложный comprehension ухудшает читаемость. Если внутри несколько условий, вложенных циклов или побочных эффектов, обычный цикл часто понятнее.

Круглые скобки создают не `tuple comprehension`, а генераторное выражение:

```python
squares = (number**2 for number in range(5))
```

## Как объединить элементы с индексами?

Для этого используют `enumerate()`:

```python
names = ["Alice", "Bob"]

for index, name in enumerate(names, start=1):
    print(index, name)
```

Это предпочтительнее ручного изменения счётчика или цикла `for index in range(len(names))`, если индекс нужен только при переборе.

## Как одновременно перебирать несколько коллекций?

Для этого используют `zip()`:

```python
names = ["Alice", "Bob"]
scores = [90, 85]

for name, score in zip(names, scores):
    print(name, score)
```

Обычный `zip()` останавливается на самой короткой коллекции. В современных версиях Python параметр `strict=True` позволяет потребовать одинаковую длину:

```python
pairs = zip(names, scores, strict=True)
```

Если длины различаются, во время перебора будет вызван `ValueError`.

## Почему `[[0] * 3] * 3` создаёт связанные строки?

Оператор `*` повторяет ссылки на один внутренний список:

```python
matrix = [[0] * 3] * 3
matrix[0][0] = 1

print(matrix)
# [[1, 0, 0], [1, 0, 0], [1, 0, 0]]
```

Все три позиции внешнего списка указывают на один объект.

Независимые строки создают через comprehension:

```python
matrix = [[0] * 3 for _ in range(3)]
```

Для неизменяемых значений повторение обычно безопасно:

```python
zeros = [0] * 3
```

## Что такое моржовый оператор?

Оператор `:=` присваивает значение внутри выражения и одновременно возвращает его.

```python
if (count := len(items)) > 10:
    print(f"Too many items: {count}")
```

Он полезен, когда одно вычисление иначе пришлось бы повторить. Чрезмерное использование ухудшает читаемость; обычное отдельное присваивание часто понятнее.

## Как работают логические операторы?

- `not value` возвращает `bool`;
- `left and right` возвращает первый ложный операнд либо последний;
- `left or right` возвращает первый истинный операнд либо последний.

```python
name = provided_name or "anonymous"
result = user is not None and user.is_active
```

`and` и `or` используют короткое замыкание: правый операнд вычисляется только при необходимости.

```python
value is not None and value.process()
```

Они возвращают не обязательно `True` или `False`:

```python
[] or "default"  # "default"
"value" and 10   # 10
```

## Как выбрать структуру данных?

| Требование | Подходящий тип |
|---|---|
| упорядоченная изменяемая последовательность | `list` |
| фиксированная последовательность | `tuple` |
| соответствие ключей значениям | `dict` |
| уникальные элементы и быстрый поиск принадлежности | `set` |
| неизменяемое множество, которое нужно хешировать | `frozenset` |
| неизменяемый текст | `str` |
| неизменяемые бинарные данные | `bytes` |
| изменяемые бинарные данные | `bytearray` |

Выбор определяется требуемыми операциями:

- нужны порядок, дубликаты и индексы — `list`;
- нужна уникальность и частые проверки `in` — `set`;
- нужен быстрый поиск значения по смысловому ключу — `dict`;
- нужно зафиксировать набор позиций — `tuple`.

Не стоит выбирать структуру только потому, что она знакомее. Например, постоянные проверки принадлежности в большом списке могут быть признаком того, что нужен `set`.

## Какие преобразования между коллекциями важно знать?

```python
list((1, 2))                       # [1, 2]
tuple([1, 2])                      # (1, 2)
set([1, 1, 2])                    # {1, 2}
dict([("name", "Alex"), ("age", 30)])
list({"a": 1, "b": 2})            # ["a", "b"] — ключи
```

Преобразование обычно создаёт новый контейнер, но не обязательно копирует вложенные объекты. При переходе к `set` теряются дубликаты и нельзя полагаться на исходный порядок.
