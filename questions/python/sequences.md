## Что такое последовательность?

**Короткий ответ**

Последовательность — это упорядоченный контейнер, поддерживающий доступ по целочисленному индексу и обычно срезы. К основным встроенным последовательностям относятся `list`, `tuple`, `range`, `str`, `bytes` и `bytearray`.

```python
values = ["a", "b", "c"]

values[0]   # "a"
values[-1]  # "c"
values[1:]  # ["b", "c"]
```

### Последовательность и итерируемый объект — одно и то же?

Нет. Последовательность является итерируемым объектом, но не каждый итерируемый объект является последовательностью. Например, `set`, `dict` и генератор можно перебирать циклом, но они не поддерживают обычный позиционный доступ `obj[0]`.

## Какие операции поддерживают последовательности?

Для большинства последовательностей доступны:

```python
value in sequence
value not in sequence
sequence[index]
sequence[start:stop:step]
len(sequence)
min(sequence)
max(sequence)
sequence.count(value)
sequence.index(value)
```

Операции `+` и `*` поддерживаются не всеми последовательностями:

```python
[1, 2] + [3]  # [1, 2, 3]
"ab" * 3      # "ababab"
```

Конкатенация неизменяемой последовательности в цикле может создавать много промежуточных объектов. Для большого числа строк используют `str.join()`.

## Чем список отличается от кортежа?

| `list` | `tuple` |
|---|---|
| изменяемый | неизменяемый |
| литерал `[1, 2]` | литерал `(1, 2)` |
| нельзя хешировать | хешируем, если хешируемы все элементы |
| подходит для изменяемой коллекции | подходит для фиксированного набора позиций |
| имеет методы изменения | не имеет методов изменения |

**Короткий ответ**

Список используют, когда состав последовательности должен меняться. Кортеж — когда набор позиций фиксирован, его полезно защитить от случайного изменения или использовать как составной ключ.

Кортеж из одного элемента обязательно содержит запятую:

```python
number = (1)       # int
one_item = (1,)    # tuple
```

Скобки не создают кортеж сами по себе — кортеж создаёт запятая.

## Что такое `range`?

`range(start, stop, step)` — неизменяемая последовательность целых чисел. Граница `stop` не включается.

```python
range(5)         # 0, 1, 2, 3, 4
range(2, 6)      # 2, 3, 4, 5
range(10, 0, -2) # 10, 8, 6, 4, 2
```

`range` лениво описывает арифметическую последовательность и не хранит отдельный объект `int` для каждого значения. Он поддерживает `len()`, индексы, срезы и быструю проверку принадлежности.

`range` является iterable, но не iterator: каждый `iter(range(...))` создаёт новый независимый итератор.

## Что такое срез?

**Короткий ответ**

Срез получает часть последовательности. Общая форма: `sequence[start:stop:step]`. Граница `stop` не включается.

```python
values = [0, 1, 2, 3, 4]

values[1:4]   # [1, 2, 3]
values[:3]    # [0, 1, 2]
values[::2]   # [0, 2, 4]
values[::-1]  # [4, 3, 2, 1, 0]
```

У среза могут быть отрицательные границы и шаг. Нулевой шаг недопустим.

Срез списка создаёт новый внешний список, но является поверхностной копией: вложенные изменяемые объекты остаются общими.

### Можно ли присваивать значение срезу?

Да, но только у изменяемых последовательностей, например у списка:

```python
values = [0, 1, 2, 3]
values[1:3] = [10, 20, 30]

print(values)  # [0, 10, 20, 30, 3]
```

При обычном срезе размер заменяемой и новой частей может различаться.

## Какие основные операции есть у списка?

```python
items = [1, 2]

items.append(3)        # добавить один объект
items.extend([4, 5])   # добавить элементы iterable
items.insert(0, 0)     # вставить перед указанным индексом
items.remove(3)        # удалить первое равное значение
last = items.pop()     # удалить и вернуть последний элемент
items.reverse()        # развернуть список на месте
items.sort()           # отсортировать список на месте
items.clear()          # удалить все элементы
```

Методы, изменяющие список на месте, обычно возвращают `None`. Поэтому следующий код ошибочен:

```python
items = [3, 1, 2]
items = items.sort()   # items теперь равен None
```

## Чем `append` отличается от `extend`?

`append(x)` добавляет `x` как один элемент, а `extend(iterable)` добавляет каждый элемент итерируемого объекта.

```python
first = [1]
first.append([2, 3])   # [1, [2, 3]]

second = [1]
second.extend([2, 3])  # [1, 2, 3]
```

Операция `items += iterable` для списка по смыслу близка к `extend`.

## Чем `remove`, `pop` и `del` отличаются?

- `remove(value)` удаляет первое равное значение и вызывает `ValueError`, если его нет;
- `pop(index)` удаляет и возвращает элемент по индексу, по умолчанию последний;
- `del` удаляет элемент, срез или само имя и ничего не возвращает.

```python
items = ["a", "b", "c"]

items.remove("b")  # удалить по значению
value = items.pop()  # удалить и вернуть "c"
del items[0]       # удалить по индексу
```

Удаление элемента из середины списка имеет сложность `O(n)`, потому что последующие элементы приходится сдвигать.

## Чем `sorted` отличается от `list.sort`?

`sorted(iterable)` принимает любой итерируемый объект и возвращает новый список. `list.sort()` сортирует существующий список на месте и возвращает `None`.

```python
values = [3, 1, 2]

new_values = sorted(values)  # values не изменился
values.sort()                # values изменён
```

Обе операции поддерживают `key` и `reverse`:

```python
users = [
    {"name": "Bob", "age": 25},
    {"name": "Alice", "age": 30},
]

by_age = sorted(users, key=lambda user: user["age"])
```

Сортировка Python стабильна: элементы с одинаковым ключом сохраняют взаимный порядок.

## Как сравниваются последовательности?

Последовательности одного совместимого вида сравниваются лексикографически: слева направо до первой различающейся пары.

```python
[1, 2, 3] < [1, 4]  # True, потому что 2 < 4
[1, 2] < [1, 2, 0]  # True: общий префикс короче
"abc" < "abd"        # True
```

Равенство требует равной длины и попарно равных элементов.

В Python 3 упорядочивающее сравнение несовместимых типов обычно вызывает `TypeError`:

```python
[1, 2] < ["1", "2"]  # TypeError
```

## Чем `str`, `bytes` и `bytearray` отличаются?

- `str` — неизменяемая последовательность Unicode-символов;
- `bytes` — неизменяемая последовательность байтов;
- `bytearray` — изменяемая последовательность байтов.

Для преобразования текста в байты используют кодирование, для обратного преобразования — декодирование:

```python
payload = "Привет".encode("utf-8")
text = payload.decode("utf-8")
```

Кодировку нужно указывать осознанно. Одинаковый текст может иметь разное двоичное представление в разных кодировках.

## Чем поверхностная копия отличается от глубокой?

**Короткий ответ**

Поверхностная копия создаёт новый внешний контейнер, но оставляет ссылки на вложенные объекты. Глубокая копия рекурсивно копирует вложенные объекты.

```python
import copy

original = [[1], [2]]
shallow = copy.copy(original)
deep = copy.deepcopy(original)

original[0].append(3)

print(shallow)  # [[1, 3], [2]]
print(deep)     # [[1], [2]]
```

Поверхностную копию списка также создают:

```python
copy_1 = items.copy()
copy_2 = list(items)
copy_3 = items[:]
```

`deepcopy` нужен не всегда: он дороже, а некоторые объекты, например открытые файлы или соединения, нельзя осмысленно дублировать таким способом.

## Как соединить и разбить строки?

`join()` соединяет строки, помещая разделитель между ними:

```python
parts = ["api", "v1", "users"]
path = "/".join(parts)
# "api/v1/users"
```

Все элементы должны быть строками. Для других типов нужно явное преобразование:

```python
text = ",".join(map(str, [1, 2, 3]))
```

`split()` разбивает строку:

```python
"a,b,c".split(",")  # ["a", "b", "c"]
"  a   b  ".split() # ["a", "b"]
```

Без аргумента `split()` группирует последовательности пробельных символов и отбрасывает пробелы по краям.

### Можно ли изменить символ строки?

Нет, `str` неизменяем:

```python
text = "cat"
text[0] = "b"  # TypeError
```

Нужно создать новую строку:

```python
text = "b" + text[1:]
```
