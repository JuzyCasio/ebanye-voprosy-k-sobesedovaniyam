## Как соединить и разбить строки?

`join()` соединяет строки, помещая разделитель между ними:

```python
parts = ["api", "v1", "users"]
path = "/".join(parts)
# "api/v1/users"
```

Все элементы должны быть строками. Для других типов нужно явное преобразование:

```python
text = ",".join(map(str, [1, 2, 3]))
```

`split()` разбивает строку:

```python
"a,b,c".split(",")  # ["a", "b", "c"]
"  a   b  ".split() # ["a", "b"]
```

Без аргумента `split()` группирует последовательности пробельных символов и отбрасывает пробелы по краям.

### Можно ли изменить символ строки?

Нет, `str` неизменяем:

```python
text = "cat"
text[0] = "b"  # TypeError
```

Нужно создать новую строку:

```python
text = "b" + text[1:]
```
