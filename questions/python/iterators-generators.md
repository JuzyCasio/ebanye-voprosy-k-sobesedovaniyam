# Итерируемые объекты, итераторы и генераторы

[← К разделу Python](../python.md)

## Что такое итерируемый объект?

Итерируемый объект — это объект, элементы которого можно перебирать в цикле `for`. Например: список, кортеж, строка, словарь, множество и `range`.

Технически итерируемым считается объект, от которого можно получить итератор с помощью `iter()`.

```python
values = [1, 2, 3]
iterator = iter(values)
```

Не каждый итерируемый объект хранит все элементы в памяти. Например, генератор вычисляет и выдаёт значения по мере необходимости.

## Что такое итератор?

**Короткий ответ**

Итератор выдаёт элементы по одному и помнит, на каком месте остановился. Следующий элемент получают через `next()`. Когда элементы заканчиваются, возникает `StopIteration`.

```python
iterator = iter([10, 20])

next(iterator)  # 10
next(iterator)  # 20
next(iterator)  # StopIteration
```

Протокол итератора состоит из:

- `__iter__()`, который обычно возвращает `self`;
- `__next__()`, который возвращает следующий элемент или возбуждает `StopIteration`.

```python
class Countdown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current == 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value
```

## Что происходит в цикле `for`?

Цикл `for` сначала получает итератор с помощью `iter()`, а затем вызывает `next()`, пока элементы не закончатся.

Упрощённо это выглядит так:

```python
iterator = iter(iterable)

while True:
    try:
        item = next(iterator)
    except StopIteration:
        break
    process(item)
```

Сам цикл перехватывает `StopIteration`. Поэтому список не «двигает индекс» специально для `for`: его итератор хранит текущую позицию.

Изменять размер списка или словаря во время обхода опасно. Для словаря это обычно приводит к `RuntimeError`; для списка можно получить пропуски и неожиданное поведение. Часто обходят копию или создают новую коллекцию.

## Является ли `range` итератором?

Нет. `range` — неизменяемая итерируемая последовательность, от которой можно получать независимые итераторы.

```python
numbers = range(3)

first = iter(numbers)
second = iter(numbers)

next(first)   # 0
next(first)   # 1
next(second)  # 0
```

Сам `range` не исчерпывается и поддерживает `len()`, индексы и срезы.

## Что такое генератор?

Генератор — это удобный способ создать итератор. Он выдаёт значения по одному, а не создаёт всю коллекцию сразу, и помнит место, на котором остановился.

Генераторы создаются:

1. генераторной функцией с `yield`;
2. генераторным выражением.

```python
def squares(limit):
    for number in range(limit):
        yield number**2


expression = (number**2 for number in range(5))
```

Вызов генераторной функции не выполняет её тело сразу, а возвращает объект-генератор.

## Как создать генератор?

### Генераторная функция

```python
def read_ids(rows):
    for row in rows:
        yield row["id"]
```

### Генераторное выражение

```python
ids = (row["id"] for row in rows)
```

### Собственный класс-итератор

Класс с `__iter__` и `__next__` технически создаёт итератор, но не объект типа generator. Такой вариант нужен, когда состояние удобно описывать объектом с дополнительными методами.

## Что делает `yield`?

`yield` выдаёт очередное значение и ставит выполнение функции на паузу. При следующем `next()` функция продолжит работу с места остановки.

```python
def example():
    print("start")
    yield 1
    print("continue")
    yield 2
```

Обычный `return` завершает генератор. `return value` превращается в `StopIteration(value)` и обычно используется при делегировании через `yield from`.

## Чем генератор отличается от списка?

Список сразу хранит все элементы в памяти. Генератор вычисляет и выдаёт элементы по одному, поэтому обычно расходует меньше памяти, но его нельзя читать по индексу и обычно нельзя повторно перебрать.

| Список | Генератор |
|---|---|
| хранит все элементы | вычисляет по требованию |
| поддерживает индексы и `len()` | обычно не поддерживает |
| можно обходить многократно | обычно одноразовый |
| требует память на все элементы | хранит только состояние вычисления |
| ошибки вычисления возникают при создании списка | ошибки могут возникнуть позже, при итерации |

```python
list_values = [number**2 for number in range(1_000_000)]
lazy_values = (number**2 for number in range(1_000_000))
```

Генератор полезен для больших или бесконечных потоков. Список удобнее, когда значения нужны многократно или требуется произвольный доступ.

## Можно ли получить элемент генератора по индексу?

Обычно нет: генератор не реализует протокол последовательности.

```python
generator = (number**2 for number in range(5))
generator[2]  # TypeError
```

Можно последовательно дойти до элемента, например через `next()` или `itertools.islice()`, но предыдущие значения будут потреблены.

```python
from itertools import islice

third = next(islice(generator, 2, None))
```

Чтобы получить список:

```python
values = list(generator)
```

После этого исходный генератор будет исчерпан.

## Что такое `yield from`?

`yield from` по очереди выдаёт все элементы другого итерируемого объекта. Он позволяет не писать дополнительный вложенный цикл.

```python
def flatten(groups):
    for group in groups:
        yield from group
```

Это не просто короткая запись внутреннего цикла: при работе с генератором делегируются также `send()`, `throw()`, `close()` и возвращаемое подгенератором значение.

## Какие методы есть у генератора?

- `next(generator)` или `generator.__next__()` — продолжить до следующего `yield`;
- `send(value)` — продолжить и передать значение внутрь выражения `yield`;
- `throw(exception)` — возбудить исключение в точке приостановки;
- `close()` — завершить генератор через `GeneratorExit`.

```python
def receiver():
    while True:
        value = yield
        print(value)


generator = receiver()
next(generator)       # запустить до первого yield
generator.send("hi")
generator.close()
```

Для обычного получения значений чаще всего достаточно `for` и `next()`.

## Что такое сопрограмма?

Сопрограмма — это функция, которая может приостановить работу во время ожидания, дать выполниться другим задачам, а затем продолжить с того же места.

Исторически в Python использовали генераторы с `send()`. Современные нативные корутины объявляют через `async def` и приостанавливают через `await`:

```python
async def fetch():
    result = await client.get("/users")
    return result
```

Вызов `async def` возвращает объект coroutine. Для выполнения ему нужен event loop, обычно через `asyncio.run()` или задачу `asyncio.create_task()`.
