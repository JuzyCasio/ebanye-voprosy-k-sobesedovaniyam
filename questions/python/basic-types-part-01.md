## Какие основные типы существуют в Python?

**Короткий ответ**

Основные встроенные типы можно разделить на несколько групп:

- числа: `int`, `float`, `complex`;
- логический тип: `bool`;
- текст: `str`;
- последовательности: `list`, `tuple`, `range`;
- отображения: `dict`;
- множества: `set`, `frozenset`;
- бинарные данные: `bytes`, `bytearray`, `memoryview`;
- отсутствие значения: `None`, имеющее тип `NoneType`.

| Группа | Типы | Пример |
|---|---|---|
| целые и вещественные числа | `int`, `float` | `10`, `3.14` |
| комплексные числа | `complex` | `2 + 3j` |
| логические значения | `bool` | `True`, `False` |
| текст | `str` | `"hello"` |
| последовательности | `list`, `tuple`, `range` | `[1, 2]`, `(1, 2)`, `range(3)` |
| отображения | `dict` | `{"id": 10}` |
| множества | `set`, `frozenset` | `{1, 2}`, `frozenset({1, 2})` |
| бинарные данные | `bytes`, `bytearray`, `memoryview` | `b"abc"` |
| отсутствие значения | `NoneType` | `None` |

`bool` является подклассом `int`: `True == 1` и `False == 0`. Это особенность системы типов Python, но обычно логические значения не стоит использовать вместо чисел.

## Что означает динамическая типизация?

**Короткий ответ**

В Python у переменной нет навсегда закреплённого типа. Во время выполнения программы она может сначала ссылаться на число, а потом, например, на строку. Тип принадлежит самому объекту.

Совместимость типов при выполнении операции проверяется во время работы программы:

```python
value = 10
value = "ten"  # допустимо: теперь value ссылается на строку

"10" + 5  # TypeError возникнет во время выполнения
```

При **статической типизации** тип переменной или выражения известен и проверяется статическим анализатором до запуска программы. Python остаётся динамически типизированным языком даже при использовании аннотаций.

Аннотация типа сама по себе не меняет поведение интерпретатора:

```python
age: int = 30
age = "thirty"  # интерпретатор разрешит, но статический анализатор предупредит
```

Аннотации помогают людям, IDE и инструментам вроде `mypy` или `pyright`, но сами по себе не запрещают присвоить значение другого типа.

### А что тогда означает сильная типизация?

Динамическая/статическая и сильная/слабая типизация — разные характеристики.

Python часто называют языком с **сильной типизацией**, потому что он обычно не смешивает несовместимые типы автоматически: например, строку и число нельзя сложить без явного преобразования. Но у терминов «сильная» и «слабая типизация» нет единого строгого определения, поэтому для ответа про динамическую типизацию они не нужны.
