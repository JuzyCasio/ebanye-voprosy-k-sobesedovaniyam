## В чём проблема изменяемого аргумента по умолчанию?

**Короткий ответ**

Значения аргументов по умолчанию вычисляются один раз — при создании функции. Изменяемый объект будет общим для всех вызовов, в которых аргумент не передан.

```python
# Плохо
def collect(value, result=[]):
    result.append(value)
    return result
```

```python
# Хорошо
def collect(value, result=None):
    if result is None:
        result = []
    result.append(value)
    return result
```

Иногда общее состояние создают намеренно, но тогда это должно быть явно и понятно из кода.
