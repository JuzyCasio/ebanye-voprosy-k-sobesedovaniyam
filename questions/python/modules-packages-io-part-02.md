## Как открыть и закрыть файл?

Файл открывают функцией `open()`. Обычно её используют вместе с `with`, чтобы файл гарантированно закрылся.

```python
with open("report.txt", "w", encoding="utf-8") as file:
    file.write("passed")
```

Основные режимы:

- `r` — чтение;
- `w` — запись с очисткой существующего файла;
- `a` — добавление в конец;
- `x` — создание только нового файла;
- `b` — бинарный режим;
- `+` — чтение и запись.

`with` закроет файл даже при возникновении ошибки. Поэтому файлы обычно открывают именно через контекстный менеджер.

## Чем текстовый файл отличается от бинарного?

Текстовый файл читают и записывают как строки `str`, указывая кодировку. Бинарный файл читают и записывают как `bytes`.

```python
with open("data.json", encoding="utf-8") as file:
    text = file.read()

with open("image.png", "rb") as file:
    payload = file.read()
```

Кодировку текстового файла лучше указывать явно.

## Что делают `seek` и `tell`?

- `tell()` возвращает текущую позицию потока;
- `seek(offset, whence)` меняет позицию.

```python
with open("data.bin", "rb") as file:
    first = file.read(4)
    position = file.tell()
    file.seek(0)
```

В текстовом режиме позиция не обязана быть простым номером символа из-за кодировки и преобразования переводов строк.

## Что такое `StringIO` и `BytesIO`?

`StringIO` и `BytesIO` ведут себя похоже на файлы, но хранят данные в памяти. `StringIO` работает со строками, а `BytesIO` — с байтами.

```python
from io import BytesIO, StringIO

text_stream = StringIO()
text_stream.write("report")

binary_stream = BytesIO(b"\x00\x01")
```

Для AQA они удобны, чтобы тестировать код, ожидающий файл, без реального доступа к диску.

## Чем `dump` отличается от `dumps`, `load` от `loads`?

В модуле `json`:

- `dump(obj, file)` записывает JSON в файловый объект;
- `dumps(obj)` возвращает строку;
- `load(file)` читает из файлового объекта;
- `loads(text)` читает строку или байтовое представление.

```python
import json

payload = json.dumps({"passed": True})
data = json.loads(payload)
```

Для нестандартных типов используют `default=` при сериализации или `JSONEncoder`; при чтении — `object_hook` и другие параметры.

## Чем `dict` отличается от JSON?

`dict` — структура данных внутри Python. JSON — текстовый формат, который используют для передачи и хранения данных между разными системами.

Основные различия:

- ключи JSON-объекта всегда строки;
- JSON поддерживает ограниченный набор значений: object, array, string, number, boolean и null;
- `tuple`, `set`, `datetime`, пользовательские классы напрямую не представлены;
- `None`, `True`, `False` превращаются в `null`, `true`, `false`;
- не каждое число JSON без потерь соответствует конкретному числовому типу другой системы.

```python
json.dumps({1: "value"})
# '{"1": "value"}'
```

## Чем JSON отличается от `pickle`?

JSON — текстовый формат, понятный разным языкам программирования. `pickle` — формат Python, который умеет сохранять больше Python-объектов, но небезопасен для недоверенных данных.

| JSON | pickle |
|---|---|
| межъязыковой текстовый формат | Python-специфичный бинарный формат |
| ограниченный набор типов | поддерживает много Python-объектов |
| удобен для API | удобен для доверенных внутренних данных |
| безопаснее парсить недоверенные данные | может выполнить опасный код при загрузке |

Никогда нельзя делать `pickle.loads()` для данных из недоверенного источника.

## Как вывести сообщение в `stderr`?

Нужно передать `sys.stderr` в параметр `file` функции `print()` или вызвать `sys.stderr.write()`.

```python
import sys

print("error", file=sys.stderr)
sys.stderr.write("error\n")
```

Для рабочего приложения обычно лучше модуль `logging`, который позволяет управлять уровнями, форматами и обработчиками.
