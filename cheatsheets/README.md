# Быстрый повтор

[← На главную](../README.md)

Короткие шпаргалки для повторения перед собеседованием AQA/SDET. Здесь только определения, сравнения, команды и типовые ловушки. Подробные объяснения находятся в основной базе вопросов.

Шпаргалки не являются заменой полных конспектов. Для изучения новой темы сначала открой соответствующий подробный раздел, а сюда возвращайся для самопроверки и повторения.

## Шпаргалки

1. [Теория тестирования](testing.md) — принципы, виды, тест-дизайн, документация, риски и автоматизация.
2. [Python](python.md) — типы, коллекции, функции, ООП, итераторы, GIL и конкурентность.
3. [Pytest](pytest.md) — запуск, фикстуры, параметризация, моки, плагины и CI.
4. [API-автоматизация на Python](api-testing.md) — requests, клиенты, контракты, авторизация, retry и polling.
5. [Web и UI](web-ui.md) — Selenium, Playwright, локаторы, ожидания, архитектура и flaky-тесты.
6. [Сети и HTTP](networks.md) — TCP/IP, DNS, HTTP, TLS и диагностика.
7. [Брокеры сообщений](message-brokers.md) — Kafka, RabbitMQ, доставка и тестирование.
8. [SQL](sql.md) — запросы, JOIN, агрегации, индексы и транзакции.
9. [Linux](linux.md) — файлы, процессы, права, логи, сеть и диагностика.
10. [Архитектура тестового фреймворка](test-framework-architecture.md) — слои, зависимости, fixtures, clients, данные, паттерны, parallel run и CI.

## Как повторять

1. Прочитать одну шпаргалку целиком.
2. Попытаться проговорить определения своими словами.
3. Выполнить команды или примеры без копирования.
4. По непонятной теме перейти в подробный раздел базы.
