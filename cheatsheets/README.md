# Быстрый повтор

[← На главную](../README.md)

Короткие шпаргалки для повторения перед собеседованием AQA/SDET. Здесь только определения, сравнения, команды и типовые ловушки. Подробные объяснения находятся в основной базе вопросов.

## Шпаргалки

1. [Python](python.md) — типы, коллекции, функции, ООП, итераторы, GIL и конкурентность.
2. [Pytest](pytest.md) — запуск, фикстуры, параметризация, моки, плагины и CI.
3. [Сети и HTTP](networks.md) — TCP/IP, DNS, HTTP, TLS и диагностика.
4. [Брокеры сообщений](message-brokers.md) — Kafka, RabbitMQ, доставка и тестирование.
5. [SQL](sql.md) — запросы, JOIN, агрегации, индексы и транзакции.
6. [Linux](linux.md) — файлы, процессы, права, логи, сеть и диагностика.

## Как повторять

1. Прочитать одну шпаргалку целиком.
2. Попытаться проговорить определения своими словами.
3. Выполнить команды или примеры без копирования.
4. По непонятной теме перейти в подробный раздел базы.
