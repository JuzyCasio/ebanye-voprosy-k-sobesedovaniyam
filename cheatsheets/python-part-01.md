## Типы и объекты

- Python использует динамическую типизацию: тип принадлежит объекту, а переменная является именем, которое на него ссылается.
- Изменяемый объект можно изменить после создания. Неизменяемый — нельзя.
- Изменяемые: `list`, `dict`, `set`, `bytearray`.
- Неизменяемые: `int`, `float`, `bool`, `complex`, `str`, `tuple`, `frozenset`, `range`, `bytes`, `None`.

```python
value = 10
value = "ten"  # допустимо
```

### `==` и `is`

- `==` сравнивает значения;
- `is` проверяет, один ли это объект;
- с `None` используют `is None` и `is not None`.

## Основные коллекции

| Тип | Порядок | Дубликаты | Изменяемость | Основное применение |
|---|---|---|---|---|
| `list` | да | да | да | изменяемая последовательность |
| `tuple` | да | да | нет | фиксированный набор значений |
| `dict` | порядок добавления | ключи уникальны | да | пары «ключ — значение» |
| `set` | не полагаться | нет | да | уникальность и быстрый `in` |
| `frozenset` | не полагаться | нет | нет | неизменяемое множество |

### Частые операции

```python
items.append(value)       # добавить один элемент
items.extend(values)      # добавить несколько
items.pop()               # удалить и вернуть
items.remove(value)       # удалить по значению

mapping.get("key", 0)     # без KeyError
mapping.items()           # пары ключ-значение

left | right              # объединение множеств
left & right              # пересечение
left - right              # разность
```

### Хешируемость

Хешируемый объект имеет стабильный хеш и может быть ключом `dict` или элементом `set`.

- обычно хешируемы неизменяемые объекты;
- `list`, `dict` и `set` нехешируемы;
- кортеж хешируем, только если хешируемы все его элементы.

## Функции

```python
def request(method, *args, timeout=5, **kwargs):
    ...
```

- `*args` собирает дополнительные позиционные аргументы в `tuple`;
- `**kwargs` собирает дополнительные именованные аргументы в `dict`;
- значения по умолчанию вычисляются один раз при создании функции.

```python
# Плохо
def collect(value, result=[]):
    result.append(value)
    return result


# Хорошо
def collect(value, result=None):
    if result is None:
        result = []
    result.append(value)
    return result
```

### Передача аргументов

Объектная ссылка передаётся по значению. Функция может изменить переданный изменяемый объект, но обычным присваиванием не может переназначить внешнюю переменную.

### LEGB

Python ищет имя в порядке:

1. `Local` — текущая функция;
2. `Enclosing` — внешняя функция;
3. `Global` — модуль;
4. `Builtins` — встроенные имена.

## Comprehensions

```python
squares = [number**2 for number in range(5)]
unique = {item.id for item in items}
by_id = {item.id: item for item in items}
```

Использовать, пока выражение остаётся понятным. Сложную логику лучше записать обычным циклом.

## Итераторы и генераторы

- итерируемый объект можно использовать в `for`;
- итератор выдаёт элементы через `next()` и помнит позицию;
- генератор — удобный итератор, созданный с помощью `yield`;
- генератор вычисляет значения по одному и обычно экономит память;
- после полного обхода генератор исчерпан.

```python
def read_ids(rows):
    for row in rows:
        yield row["id"]
```

## Декораторы и `with`

- декоратор оборачивает функцию или класс и добавляет поведение;
- `functools.wraps` сохраняет имя и документацию исходной функции;
- контекстный менеджер выполняет подготовку и гарантированную очистку вокруг блока `with`.

```python
from functools import wraps


def log_call(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print(function.__name__)
        return function(*args, **kwargs)

    return wrapper
```

## Исключения

```python
try:
    value = int(raw_value)
except ValueError as error:
    handle(error)
else:
    use(value)
finally:
    cleanup()
```

- ловить конкретные исключения;
- `raise` повторно выбрасывает текущую ошибку;
- `raise NewError() from error` сохраняет причину;
- пользовательское исключение обычно наследуют от `Exception`.
