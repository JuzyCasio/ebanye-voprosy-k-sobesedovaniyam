## ООП

- класс описывает данные и поведение объектов;
- объект — экземпляр класса;
- инкапсуляция скрывает внутренние детали за понятными методами;
- наследование создаёт класс на основе другого;
- полиморфизм позволяет одинаково работать с объектами разных типов;
- абстракция показывает, что объект делает, и скрывает реализацию;
- композиция означает, что один объект использует другой.

### Методы

| Метод | Что получает |
|---|---|
| обычный | объект `self` |
| `@classmethod` | класс `cls` |
| `@staticmethod` | ничего автоматически |

- `__new__` создаёт объект;
- `__init__` настраивает созданный объект;
- MRO определяет порядок поиска методов в иерархии;
- `super()` переходит к следующему классу в MRO.

## Копирование

- поверхностная копия создаёт новую внешнюю коллекцию, но оставляет общие вложенные объекты;
- глубокая копия через `copy.deepcopy()` копирует и вложенные объекты.

## Файлы, JSON и время

```python
with open("data.json", encoding="utf-8") as file:
    data = json.load(file)
```

- `json.dumps()` — объект в строку JSON;
- `json.loads()` — строка JSON в объект;
- для API и тестов время обычно хранят и сравнивают в UTC;
- `datetime` без timezone называется naive, с timezone — aware.

## Потоки, процессы и `asyncio`

- поток использует общую память процесса;
- процесс имеет отдельную память;
- GIL в обычном CPython позволяет одному потоку выполнять Python-код в один момент;
- потоки полезны для блокирующего I/O;
- процессы — для вычислений на чистом Python;
- `asyncio` — для большого количества конкурентных I/O-операций через async API;
- `pytest-xdist` обычно запускает независимые тесты в worker-процессах.

## Сложность частых операций

| Операция | Средняя сложность |
|---|---|
| `list[index]` | `O(1)` |
| `list.append()` | `O(1)` амортизированно |
| `value in list` | `O(n)` |
| вставка в начало списка | `O(n)` |
| `dict[key]` | `O(1)` |
| `key in dict` | `O(1)` |
| `value in set` | `O(1)` |
| сортировка | `O(n log n)` |

## Типовые ловушки

- mutable-объект как аргумент по умолчанию;
- `is` вместо `==`;
- ожидание результата от `list.append()` или `list.sort()` — они возвращают `None`;
- изменение списка во время обхода;
- `except:` или `except Exception: pass`;
- общий изменяемый объект между тестами;
- сравнение `float` через точное равенство;
- блокирующий вызов внутри async-кода.
